# Telecom Customer Support Knowledge: Late Rating and Usage Mediation

## Scope
Covers usage events received, mediated, rated, or billed after the original service period.

## Process Concepts
- Network event generation
- Mediation and normalization
- Usage validation
- Rating
- Billing aggregation
- Invoice generation

## Common Causes
- Delayed network records
- Roaming partner delays
- Mediation backlog
- Rating-system delay
- Reprocessing or correction
- Event rejection and later recovery

## Key Checks
- Service usage timestamp
- Event receipt timestamp
- Rating timestamp
- Original usage period
- Current bill period
- Event identifier
- Related bill item
- Late-rating indicator

## Support Response
Explain when the service was used and when it was billed. A late-rated charge is not automatically a duplicate or an error.
